This article explains all the types of flashcards RemNote offers in some detail. If you haven't created any flashcards at all yet, **start with the [Flashcard Basics](https://help.remnote.com/en/articles/8663109-flashcard-basics) article** to get the basics down first, then come back here!

RemNote supports many types of flashcards.

- Type `>>` or `==` to create a _[Basic](https://help.remnote.com/en/articles/6025481-creating-flashcards#h_594d2e06f8)_ card (`<<` for a reverse one, `<>` for a bidirectional one).

- Type `::`to create a bidirectional _[Concept](https://help.remnote.com/en/articles/6025481-creating-flashcards#h_11a421826d)_ card (`:>` for forward-only, `:<` for reverse-only).

- Type `;;` to create a _[Descriptor](https://help.remnote.com/en/articles/6025481-creating-flashcards#h_b14057339d)_ card (`;<` for reverse, `;<>` for bidirectional).

- Type `{{`,or highlight some text and press `{`,to create a _[Cloze](https://help.remnote.com/en/articles/6025481-creating-flashcards#h_80f8c0a794)_(fill-in-the-blank) card.

- Type `A)` after creating a Basic card to create a _[Multiple-Choice](https://help.remnote.com/en/articles/6025481-creating-flashcards#h_4684ff9e1e)_ card.

- Ctrl+click on an image (Cmd+click on a Mac) to create an [Image Occlusion](https://help.remnote.com/en/articles/6511625-image-occlusion-cards) card.

- Type `-` after you've created a flashcard, to immediately [disable it](https://help.remnote.com/en/articles/7950982-setting-priorities-and-disabling-flashcards) (e.g., type `>>-` for a disabled Basic card)


You can make the first three types of cards into [Multi-Line](https://help.remnote.com/en/articles/9216774-multi-line-list-set-flashcards) cards either by typing the trigger character three times instead of twice (for example, type `>>>` for a forward multi-line _Basic_ card), or by pressing Enter/Return after typing it twice.

To learn more about each type of flashcard, read on!

Once you’ve created flashcards, you can get an overview of them and practice them from the [Flashcard Home](https://help.remnote.com/en/articles/7925835-the-flashcard-home).

If you have a lot of content to cover or you want to try things out before worrying about how to create good flashcards, you can [generate flashcards with AI](https://help.remnote.com/en/articles/10102901-generating-flashcards-with-ai). This will use the same types of flashcards explained below, but rather than specifying what's on the front and back of each yourself, you'll paste some text and RemNote will reformat it as flashcards.

# Basic cards

Basic cards are the simplest type of flashcard. They have two sides, which are generally a _prompt_(question) and an _answer_, but you can put whatever you like on each side. By default, a single card is created in the forward direction (show the prompt and ask for the answer), but you can instead choose to create a single card in the reverse direction (show the answer and ask for the prompt), create cards in both directions, or create no cards at all. (You might choose not to create flashcards in either direction if, for example, you temporarily don't want to study a particular question. See [Setting Priorities and Disabling Flashcards](https://help.remnote.com/en/articles/7950982-setting-priorities-and-disabling-flashcards) for more information.)

To create a Basic card, type the prompt, then `>>` or `==`, then the response. When you type `>>`, RemNote will change it into a pretty right arrow, indicating that you have one flashcard in the forward direction. Clicking the arrow will allow you to change the card type, select what direction(s) to show flashcards in (the direction the arrow points will update to match), enable or disable a card, enable the [Type in Answer](https://help.remnote.com/en/articles/7752298-typing-in-answers) mode or delete the card completely.

You can also see what your flashcard will look like during practice by clicking the preview button on the right:

![The Flashcard Preview panel opened from the preview button, showing the card front with its answer hidden and a blue Show Answer button.](https://downloads.intercomcdn.com/i/o/akxf7g7x/2544280801/f18ac9da84b2ccf07f14284d702e/03-CleanShot_2026-06-12_at_15_33_51_402x.png?expires=1787970600&signature=bda875ea292d7a29e57f6c01bf411226c787bce4dc920c3ddd2d2f55c0f8770e&req=diUjEst2nYlfWPMW1HO4zcb5UoFJuvG0mT178NQvq5qwMHs3ySSqmKy9mMki%0AlzaM7vodAxQ1tLSwtGc%3D%0A)

As a shortcut, you can instead type `<<`, `<>` , or `=-` to start with only a backwards card, cards in both directions, or no cards, respectively.

## Context

When you study a flashcard in RemNote, it will show all of the ancestors of the bullet the card was generated from – that is, all the bullets above it in the outline hierarchy – to provide you with context on the question you're being asked to answer, so you don't need to include this information in every prompt.

For example, consider this short block of notes:

![A short outline with Cell at the top, Mitochondria and its definition indented under it, and a further indented question about how mitochondria originated.](https://downloads.intercomcdn.com/i/o/715652423/497eea8e1ad929ad4fa0ac86/image.png?expires=1787970600&signature=abb0eba6510f3c1c3faf89472f8780c22e1a1bf1ac317cc927646a3791b50668&req=cyEiEMx8mYNcFb4f3HP0gBGA6u6LwOcoZevLQ4qkbYQAALhPj0wVzFcBR9G4%0ASRr3UDHRdR1rxzApCQ%3D%3D%0A)

The second card will appear like this:

![The originated-from card in practice, showing its ancestor bullets Cell and Mitochondria above the question as context, including the Mitochondria answer.](https://downloads.intercomcdn.com/i/o/akxf7g7x/2544281329/cf7322a570c07d7018227a394ee2/05-CleanShot_2026-06-12_at_15_36_25_402x.png?expires=1787970600&signature=ad08067c4b5eadb9b01008b661befa54e97a8929ffbe074061d660f563e90715&req=diUjEst2nIJdUPMW1HO4zdT7RNIXcbL6djQAiXLcC96k0DO85Xal093Y9SyT%0A%2FGx%2Fdpdu%2FNLIKkX91Cc%3D%0A)

Notice that the back of the _Mitochondria_ card is included. In many cases, this is useful context. If it gives away the answer to the _How are they thought to have originated?_ card, this is usually a sign it should be a concept card instead (see immediately below). Concept cards don't show the back side here.

# Concept cards

Concept cards work much like Basic cards, but their prompt is the name of a concept (thing). Concepts are shown in **bold**, and, unlike Basic cards, concepts generate flashcards in both directions by default. (As with a Basic card, you can change what directions are tested by clicking on the arrow.) By convention, they should begin with an uppercase letter. For more on why you might want to mark things as Concepts, see [Structuring Knowledge with the Concept/Descriptor Framework](https://help.remnote.com/en/articles/6026154-structuring-knowledge-with-the-concept-descriptor-framework).

Create a Concept card by typing the name of the concept, `::` (two colons), and then its definition. You'll know that you've created a Concept card because the concept name turns **bold.**

We can improve the example above by turning **Cell** and **Mitochondria** into concept cards:

![The same outline with Cell and Mitochondria now bold and carrying two-way arrows, marking them as concept cards.](https://downloads.intercomcdn.com/i/o/akxf7g7x/2472597184/540b3b2cc6264385da1ac16dafba/CleanShot+2026-06-12+at+15_39_56%402x.png?expires=1787970600&signature=07ea2a8acf603476e1f8a23342a0662f2ff838d2693c3bae3468f7a08eabd807&req=diQgFMx3moBXXfMW1HO4zdbfIsbZMn%2BiniPvijvpPf0bcNJAgmtgL3Sfdhq%2B%0A2YWwed71eDVmtIV%2FuRU%3D%0A)

See [Creating Concept/Descriptor Flashcards](https://help.remnote.com/en/articles/6751778-creating-concept-descriptor-flashcards) for more details on this type of card.

# Descriptor cards

Descriptor cards are similar to Basic cards and Concept cards, but they describe a specific attribute of their parent Concept. They are shown in italics and are shown only in the forward direction by default. By convention, they should begin with a lowercase letter (unlike Concepts, which should begin with an uppercase letter).

Create a Descriptor card by typing the name of the attribute, `;;` (two semicolons), and then its description. You'll know that you created a Descriptor card because the attribute name turns _italic_.

We can make the example above more concise by turning the question about Mitochondria into a descriptor:

![The same outline with the mitochondria question rewritten as an italic descriptor reading how thought to have originated.](https://downloads.intercomcdn.com/i/o/akxf7g7x/2472598436/1a73ccfcff75a19db29c0b732dd0/CleanShot+2026-06-12+at+15_40_58%402x.png?expires=1787970600&signature=f61bd2d7a7b4fbc0c3d8cef5239fe3c7067fb38d66f3a8fbb6ef96ac12b0cf7e&req=diQgFMx3lYVcX%2FMW1HO4zR2j1HGkSBpXSL9%2BS11tqLo%2FOgz54U9G5NWPErFB%0A%2FoiDX1EdaN%2Bw44%2F7oHI%3D%0A)

# Cloze (fill-in-the-blank) cards

Basic, Concept, and Descriptor cards all work in the same way: you define a front side and a back side and then decide which directions to practice them in. Cloze cards work completely differently: When creating the cards, you select specific parts of a bullet's text to hide. Then when practicing the cards, you'll be asked to fill in these blanks (called _occlusions_ or _cloze deletions_).

Create Cloze cards from a bullet by selecting any text you want to occlude in it, then selecting the cloze button (dotted box icon) on the formatting toolbar or pressing the `{` key. Alternatively, create cloze cards as you type the text of a bullet by pressing `{{` before typing the text you want to occlude and `}}` when you're done.

![Text selected inside a bullet, with a red box around the cloze button, the dotted-box icon, on the formatting toolbar below.](https://downloads.intercomcdn.com/i/o/akxf7g7x/2472602244/190c17cb9d819cbec5fd112d2499/CleanShot+2026-06-12+at+15_43_24%402x.png?expires=1787970600&signature=f4af50791ab166bac26d8551883a662b48afbe9085dbfc43e45612c27d3e5590&req=diQgFM9%2Bn4NbXfMW1HO4zbc2sjGBKm0dRG7OgBzpfwnx95w3NM8AR72q%2Bub1%0AZwoqYLJn3c%2BqPT1%2BhHE%3D%0A)

You can occlude multiple sections in the same bullet; if you do this, a drop-down arrow will appear next to each occlusion, allowing you to choose whether you want all of the sections to be hidden at once or each section to be hidden individually on a separate card.

![A bullet with two separate occlusions, each showing a small drop-down arrow for choosing whether the sections are hidden together or on separate cards.](https://downloads.intercomcdn.com/i/o/akxf7g7x/2472603478/b919ea775a5e8bd0c449f5143d49/CleanShot+2026-06-12+at+15_44_34%402x.png?expires=1787970600&signature=a05d25a0ee4124e09c89061d521af1c79d105dedb0a14a35a4c4901c515a1cdf&req=diQgFM9%2BnoVYUfMW1HO4zeZ20hfI8CrclKWoglnFi7AkdeH6FlXzgu8NGSOL%0Ar9wGZqaWdSC9tnqTiR4%3D%0A)

It's also possible to generate both Basic/Concept/Descriptor cards and Cloze cards from the same bullet: simply create the Basic card, then additionally select some portions to occlude. This can come in handy if you need some extra reinforcement on a complex or long definition, for instance.

## Writing good Cloze cards

It tends to be more difficult to write effective Cloze cards than effective Basic, Concept, or Descriptor cards. This is because the specific wording of the sentence surrounding the occlusion can make it artificially easy to remember the answer when you practice it within RemNote. In real life, when you need to remember a fact or idea, you won't have the luxury of being prompted by the same exact sentence every time! For this reason, many people prefer to use Cloze cards as a small part of an overall learning strategy, rather than a primary method of generating all flashcards. When you do use Cloze cards, for best results, be sure that the text surrounding the occlusion is a good representation of the context in which you want to remember the idea, and that it doesn't give the answer away by using unusual words or context cues.

It's also worth noting that using Cloze cards, compared to Concept/Descriptor cards or even Basic cards, often makes it more difficult to find information or create cross-references in your notes in the future. If you look again at the examples about cells above, you should be able to see that it will be much easier to search or scan your notes for information about mitochondria, for example, if they're written in a Concept/Descriptor style than in a cloze style.

In some circumstances, Cloze cards are clearly the best choice, ­for instance, if you want to memorize parts of a quote. They're also faster to create in many cases, which is an important consideration if you need to learn a lot of content; creating cards is often the most time-consuming part.

# Multi-Line cards

Multi-line cards allow you to include a short list of items on the back of a card, rather than a single item. You can either reveal all the items at once on the back, or flip through them one by one.

See the article [Multi-Line (List & Set) Flashcards](https://help.remnote.com/en/articles/9216774-multi-line-list-set-flashcards) for details.

# Multiple-Choice Cards

Multiple-choice cards allow you to show a number of possible answers and select the correct one, then get feedback on your choice. These are a handy way to practice for an exam that will also be multiple-choice.

**Caution**:We don't recommend using multiple-choice cards for general-purpose learning. They're a great way to practice for an exam when you have a question bank or a series of sample questions, but for best results they should be used as part of an overall learning strategy, mixed with other types of flashcards – not exclusively.

For more details, check out [Using Multiple-Choice Flashcards Effectively](https://help.remnote.com/en/articles/8191873-using-multiple-choice-flashcards-effectively).

To create a multiple-choice card, type a question, then `==A)`. Then type the answers you want to show on the front of the card. Answer A is the default correct answer; other answers will be treated as incorrect. (The answers are presented in random order each time you practice, so you can't accidentally memorize the letter of the correct answer.)

## Practicing a multiple-choice card

When you practice a multiple choice card, you'll be shown all the answers you've added and asked to choose the correct ones.

![A multiple-choice card in practice with five numbered checkbox answers, and buttons for Can't remember and Highlight key information.](https://downloads.intercomcdn.com/i/o/akxf7g7x/2544285772/96866905d2b22205fe30c148f06a/14-CleanShot_2026-06-12_at_16_03_29_402x.png?expires=1787970600&signature=6c57acff63549de86b1fa8f41745aa67b0135761c95578382b18dc37671b65dc&req=diUjEst2mIZYW%2FMW1HO4zdJgkxT9awhg%2BRb2Q9vM0SXcB6d0%2BfHdowvmTeuQ%0AnsTYsKwMFRAWjl7j%2FR8%3D%0A)

## Explaining multiple-choice answers

When _AI Multiple Choice Explanations_ are on in _Settings > AI_, RemNote will explain why the answer you've chosen is correct or incorrect.

![A wrongly chosen answer, Assembly, flagged Not quite! with an AI explanation of why it counts as low-level, and an Ask Followup Question button.](https://downloads.intercomcdn.com/i/o/akxf7g7x/2544286854/222bf643067bb04791c4aa1e6f40/17-CleanShot_2026-06-12_at_16_06_07_402x.png?expires=1787970600&signature=64ada477283110ce8984eae536a80211924d2ae1362598221d507aa93fb762ea&req=diUjEst2m4laXfMW1HO4zWoD0H1g2oXwHX1%2FlUqGJ3pEQcs8fVk0TzNVDuVx%0AjoKrQJ1JKFwznMsRK78%3D%0A)

You can also use the [Extra Card Detail power-up](https://help.remnote.com/en/articles/6751966-extra-card-detail-power-up) to add your own explanation or other additional information to the back of the card. These will appear below the AI explanation, or instead of it if you have the AI explanation turned off.

To use this power-up, indent under one of the answers and type `/extra` or `/ecd`. For more details, see the article [Extra Card Detail Power-Up](https://help.remnote.com/en/articles/6751966-extra-card-detail-power-up).
