# What's the difference between References, Tags, and Portals?

While References, Tags, and Portals all relate bullets, they have distinct purposes and behavior.

Written by Soren Bjornstad
Updated over a week ago

References, Tags, and Portals are all ways of using the same content in multiple places and defining how things relate to each other. However, they have distinct functions.

# Summary

Suppose you have two bullets, creatively called **A** and **B**, and you're editing A and want to refer to B.

|     |     |     |     |
| --- | --- | --- | --- |
|  | **Reference** | **Tag** | **Portal** |
| **In a few words** | A link to another bullet | A note that **A** goes in category **B** | A window showing another bullet |
| **Implies that** | **B** is related to **A** | **A** is a type of **B** | **B** is used in the context of **A** |
| **How to create it** | Type `[[` or `@`, then **B** | Type `##`, then **B** | Type `((`, then **B** |\

# References\
\
A Reference is simply **a link to another bullet**. The name of the bullet you reference appears in blue, and clicking on it takes you to the referenced bullet.\
\
Use References when you want to mention some other related concept or piece of information, but don't think you'll need to immediately revisit its definition when rereading the notes later. If you think you will need the definition, you might prefer a Portal instead for greater convenience.\
\
There's one additional trick to References: In RemNote, all links are bidirectional. That is, if you create a reference from _Keyboard_ to _Computer_, you can not only see this link when looking at the _Keyboard_ bullet, but also when looking at the _Computer_ bullet. This backwards link (often called a _backlink_) appears under a _References_ section which you can access by clicking the numbered bubble to the right of the _Computer_ bullet.\
\
![The 'Computer' bullet with its References panel open, showing the 'Keyboard' bullet that references it and the document that bullet comes from.](https://downloads.intercomcdn.com/i/o/akxf7g7x/2525542763/a1d3a7085fc330ea8997f8dde5dd/CleanShot+2026-07-07+at+15_44_31%402x.png?expires=1788118200&signature=e3231a84440411ce223dc3316d9cff435ec52de2be41e5120eaa110399aaef97&req=diUlE8x6n4ZZWvMW1HO4zbA%2B6bHu81ja6wHRRHvcLnhE8%2FZ%2BCil68WZR3iWv%0AEdZBD%2FP9bkWnRCQq63Y%3D%0A)\
\
The simplest way to create a Reference is to press `[[` while typing; this will bring up an inline search box which you can use to find the bullet you want to reference.\
\
[Learn more about References](https://help.remnote.com/en/articles/6030714-references).\
\
# Tags\
\
Tagging one bullet with another means that the tagged bullet is **a type of** **the tagging bullet**. To make that more concrete, a _Keyboard_ and a _Mouse_ are both types of _Hardware_, so you might apply the _Hardware_ tag to the _Keyboard_ and _Mouse_ bullets.\
\
As with References, tags are bidirectional; you can see all of the places a tag is used by clicking the numbered bubble on the right side of that tag's bullet.\
\
![The 'Hardware' bullet with its Tags panel open, showing the two bullets tagged with it and where each one lives.](https://downloads.intercomcdn.com/i/o/akxf7g7x/2544544339/044e23f984c49b0bd2e0f56d02a5/05-CleanShot_2026-07-07_at_15_46_55_402x.png?expires=1788118200&signature=a914ed4bc2b7e889de4d5eb412a65cf72e0c5aa6e9a6bd8c93a10341f73ed846&req=diUjEsx6mYJcUPMW1HO4zYhDavBa8wprU4iuFZBuA%2FxHMcGojC1GTt%2Fl7tGd%0Aeok6LkrkzPsHjeKaWT8%3D%0A)\
\
The simplest way to add a tag to a bullet is to press `##` while typing; this will bring up an inline search box which you can use to find the bullet you want to tag the current bullet with.\
\
[Learn more about tags](https://help.remnote.com/en/articles/6030770-tags).\
\
# Portals\
\
A Portal **displays a particular bullet**, and optionally some or all of its [descendants](https://help.remnote.com/en/articles/8196578-outlines-and-terminology#h_9808744ba6), at an arbitrary place **within some other notes**. You can think of a portal like a window cut in the page with the source document placed behind it: you can see all the material at the other location right within the current document, but it's actually located in a different document, and if you update the information in one place, it will be updated in the original location as well as all its portals.\
\
Use Portals when you want to keep information that is relevant in many contexts in one centralized place, but include it directly within your notes on particular sources or more specific topics for easy review.\
\
You can tell that content is part of a portal when there is a blue bar at the left side of the content. When you click inside the portal, the bar extends into a full border around the entire portal.\
\
Again, portals are bidirectional; the numbered bubble will show any places where the current bullet has been included in a portal (unless the portal is within the current document).\
\
![Two panes side by side: the 'Additional Computer Terms' document holding the 'Cursor' bullet, and a daily document where that same bullet appears inside a portal.](https://downloads.intercomcdn.com/i/o/596255773/72d4fe3802aea7b8b74ed42f/image.png?expires=1788118200&signature=f0a8c0bba1f4dbaa67bee482c0658ac7fbe94b05132b22ab2c35442366d21a4d&req=cSkhFMx7moZcFb4f3HP0gCLc7Qla3dtdialJKOmF5JYnKxx%2BGG4PYBJmVFry%0ALiJbFgy001oe7J4ACg%3D%3D%0A)\
\
The simplest way to add a portal is to press `((` while typing; this will bring up an inline search box which you can use to find the bullet you want to show in a portal.\
\
**Note**: In other notes systems, features similar to portals may be called _transclusions_ or _mirrors_.\
\
[Learn more about portals](https://help.remnote.com/en/articles/6030742-portals).\
